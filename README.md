# Acreditación Seminario VCM

Página para confirmar asistencia y registrar en sala del *Seminario de Experiencias y mecanismos de articulación de la Vinculación con el Medio* (CRUCH).

- Página estática publicada con GitHub Pages.
- Los datos se guardan en una Google Sheet a través de Apps Script; la URL del backend va en `config.js`.
